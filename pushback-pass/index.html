The pushback pass

Six questions a skeptical reader asks of any argument. I run them on every draft before it reaches me. They work just as well on anything you read.

Each question started as a note I wrote by hand in the margin of the Florida piece, and each became a standing rule after that. The full story is in how I built the system. Here they are in general form, with the note that produced each one kept as the worked example.

Use it as a checklist, or copy the whole pass as a prompt and give it to whatever model you use, along with the op-ed, memo or draft you want argued with.

The prompt is plain text with nothing hidden in it. Paste it above the piece you want checked.
